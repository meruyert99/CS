# IB CS Games

Three browser review games for IB Computer Science:

- **Packet Run** (`packet-run.html`), Topic A2 Network
- **Trace Quest** (`trace-quest.html`), Unit B2 Programming in Python
- **Key Quest** (`key-quest.html`), Topic A3 Databases
- **SQL Revision** (`sql-revision.html`), Grade 10 ICT, SQL lesson 2 commands (gap-fill)

Plain HTML, no build step. To publish, open the repository's Settings → Pages and choose "Deploy from a branch" with `main` and `/ (root)`.
